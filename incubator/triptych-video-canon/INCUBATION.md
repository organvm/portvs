## Object and reversible artifact

N independent video-loop instances, each with persistent identity, source and
local time, presented through a deliberately authored portrait/landscape pair.
The first executable family is 3/4/5/6 loops. A separately named seven-loop
engineering experiment verifies that six is not an architectural ceiling.

The reversible artifact is normalized state plus hashed synthetic sources,
compiled through the existing Triptych FFmpeg path into paired moving exports.
A bounded, silent native-browser preview consumes the same compiler's timeline
spans; resizing changes geometry, not source selection or video-node identity.
These are engineering compositions, not artist-approved designs or recovered
historical works. `RUNTIME_RECEIPT.md` records executed gates and limits.
