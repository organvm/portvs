⚠️ CRITICAL CONSTRAINTS
═══════════════════════════════════════════════════════════════════════════════════

GitHub does NOT provide native org merge API. You must:
  ✗ Cannot merge org metadata
  ✗ Cannot merge org settings
  ✗ Cannot auto-transfer teams
  ✗ Cannot auto-transfer permissions

You CAN:
  ✓ Migrate repositories (one by one)
  ✓ Recreate team structure (manual or scripted)
  ✓ Copy branch protections
  ✓ Update webhooks

🛠️ CLI COMMANDS
═══════════════════════════════════════════════════════════════════════════════════

AUTHENTICATION
──────────────────────────────────────────────────────────────────────────────────
# Login to GitHub
gh auth login --scopes admin:org,repo

# Verify authentication
gh auth status

# Check org membership
gh org list --no-limit

LIST ORGANIZATIONS & REPOS
──────────────────────────────────────────────────────────────────────────────────
# List all orgs in enterprise
gh api graphql -f query='
  query {
    enterprise(slug: "meta-organvm") {
      organizations(first: 100) {
        nodes { login }
      }
    }
  }
'

# List all repos in org
gh api orgs/ORG_NAME/repos --paginate -q '.[] | .name'

# Count repos in org
gh api orgs/ORG_NAME/repos --paginate -q '.[] | .name' | wc -l

# Detailed repo info
gh api repos/ORG/REPO -q '{name, owner: .owner.login, isPrivate, createdAt}'

MIGRATE REPOSITORIES (CORE OPERATION)
──────────────────────────────────────────────────────────────────────────────────
# Method 1: Using installed gh-org-migrate script (RECOMMENDED)
gh-org-migrate SOURCE_ORG TARGET_ORG                 # All repos
gh-org-migrate SOURCE_ORG TARGET_ORG REPO_NAME       # Single repo

# Method 2: Manual migration (full control)
# Step 1: Clone bare
git clone --bare https://github.com/SOURCE_ORG/REPO.git REPO.git
cd REPO.git

# Step 2: Create target repo
gh repo create TARGET_ORG/REPO --private --source=none

# Step 3: Push all refs
git push --mirror https://github.com/TARGET_ORG/REPO.git

# Step 4: Verify
git ls-remote https://github.com/TARGET_ORG/REPO.git | wc -l

# Step 5: Cleanup
cd ..
rm -rf REPO.git

UPDATE LOCAL CLONES
──────────────────────────────────────────────────────────────────────────────────
# Update single clone
cd /path/to/local/repo
git remote set-url origin https://github.com/NEW_ORG/REPO.git
git remote -v

# Update all clones in directory
for repo in ~/workspace/*; do
  cd "$repo"
  REMOTE=$(git config --get remote.origin.url)
  if [[ $REMOTE == *"OLD_ORG"* ]]; then
    NEW_REMOTE=${REMOTE//OLD_ORG/NEW_ORG}
    git remote set-url origin "$NEW_REMOTE"
  fi
done

TEAMS & PERMISSIONS
──────────────────────────────────────────────────────────────────────────────────
# List teams in org
gh api orgs/ORG_NAME/teams --paginate -q '.[] | .slug'

# Add team to repo
gh api repos/TARGET_ORG/REPO/teams \
  -f team_slug='TEAM_NAME' \
  -f permission='push'

# Get repo teams
gh api repos/ORG/REPO/teams -q '.[] | {name, permission}'

BRANCH PROTECTIONS
──────────────────────────────────────────────────────────────────────────────────
# Get branch protection rules
gh api repos/ORG/REPO/branches/main/protection

# Apply basic protection to main
gh api repos/TARGET_ORG/REPO/branches/main/protection \
  -f required_status_checks=null \
  -f enforce_admins=true \
  -f required_pull_request_reviews='{"dismiss_stale_reviews":true}' \
  -f restrictions=null

WEBHOOKS
──────────────────────────────────────────────────────────────────────────────────
# List webhooks
gh api repos/ORG/REPO/hooks

# Create webhook
gh api repos/TARGET_ORG/REPO/hooks \
  -f url='https://example.com/webhook' \
  -f events='["push","pull_request"]' \
  -f active=true

GITHUB ACTIONS SECRETS
──────────────────────────────────────────────────────────────────────────────────
# List secrets
gh secret list -R ORG/REPO

# Set secret
gh secret set SECRET_NAME -R ORG/REPO -b "secret_value"

ARCHIVAL & DELETION
──────────────────────────────────────────────────────────────────────────────────
# Archive repo (read-only, but recoverable)
gh repo archive ORG/REPO --confirm

# Delete repo (PERMANENT)
gh repo delete ORG/REPO --confirm

⚡ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════════

Problem: "Push failed: remote already exists"
Solution: Create target repo first: gh repo create TARGET_ORG/REPO --source=none

Problem: "Permission denied" for migration
Solution: Verify membership: gh auth status
          Check org owner status: gh api orgs/ORG/members -q '.[] | .login'

Problem: "Refs mismatch after push"
Solution: Verify source refs: git ls-remote https://github.com/SOURCE_ORG/REPO
          Verify target refs: git ls-remote https://github.com/TARGET_ORG/REPO
          Retry push if network issue

Problem: "Local clone still points to old org"
Solution: git remote set-url origin https://github.com/NEW_ORG/REPO
          git remote -v  (verify)
          git fetch origin (sync)

Problem: "Branch protections lost after migration"
Solution: GitHub does NOT auto-migrate protections
          Reapply: gh api repos/TARGET_ORG/REPO/branches/main/protection ...
